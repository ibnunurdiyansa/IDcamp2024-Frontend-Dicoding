# 🌆 Halaman Profil Kota Bandung

Project ini merupakan **website statis sederhana** yang menampilkan profil Kota Bandung. Dibuat menggunakan **HTML5 dan CSS**, project ini bertujuan untuk melatih pemahaman struktur HTML semantik, layout dasar, serta pengelolaan aset (gambar & stylesheet).

Project ini cocok untuk **pemula** yang sedang belajar **Dasar Pemrograman Web**.

---

## 📌 Fitur Utama

- Struktur HTML5 semantik (`header`, `nav`, `main`, `article`, `section`, `aside`, `footer`)
- Navigasi internal menggunakan anchor link
- Layout konten utama dan sidebar (profil kota)
- Penyajian informasi dalam bentuk:
    - Artikel
    - Gambar
    - Tabel informasi
- Desain responsif dasar (menggunakan CSS)
