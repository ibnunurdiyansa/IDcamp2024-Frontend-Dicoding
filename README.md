# 📘 Belajar Dasar Pemrograman JavaScript

Repository ini berisi kumpulan latihan dan contoh kode **JavaScript dasar** yang digunakan untuk memahami konsep fundamental pemrograman JavaScript, mulai dari variabel, operator, fungsi, hingga struktur data dan error handling.

## 🎯 Tujuan Pembelajaran

Melalui repository ini, pembelajar diharapkan mampu:

- Memahami cara kerja JavaScript di lingkungan runtime
- Menggunakan variabel `const` dan `let` dengan benar
- Memahami tipe data dan konversinya
- Menggunakan operator (unary, binary, ternary)
- Membuat dan memanggil function
- Mengelola array, object, dan map
- Menggunakan destructuring
- Menerapkan conditional statement & looping
- Menangani error menggunakan `try...catch`
- Membuat logika sederhana dan terstruktur
